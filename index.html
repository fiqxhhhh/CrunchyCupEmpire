Tab pesanan mesti dinamakan CCE_Orders; tab menu CCE_Menu_Config akan dicipta automatik. Di Project Settings → Script Properties, tetapkan GROQ_API_KEY dan kata laluan baru yang kuat untuk CCE_ADMIN_SYAFIQAH_PASSWORD, CCE_ADMIN_JUJU_PASSWORD, CCE_ADMIN_AISYAH_PASSWORD dan CCE_ADMIN_QISTINA_PASSWORD. Jangan simpan kunci atau kata laluan dalam HTML. Spreadsheet kekal private; hanya Web App perlu akses Anyone. Selepas kemas kini, edit deployment Web App sedia ada supaya URL kekal sama.
